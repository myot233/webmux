# 终端、输入与移动端

## D. 终端操作、续接、多设备与生命周期

- **US-D01 使用交互终端**：作为使用者，我希望在浏览器里直接键入、查看彩色输出并操作全屏 TUI，以便像使用本地终端一样工作。
  验收要点：
  - 原始 PTY 字节送入 xterm；
  - 支持控制序列与终端尺寸适配；
  - 终端输出不被当作普通聊天文本重排；
  - 空闲输出与回显立即送达，连续输出（如 resize 重绘）按约 60 FPS 合并；
  - 高吞吐输出保持字节顺序并在退出前送完；
  - 程序以 DEC 2026 同步输出重绘时，文字与图片在同一帧切换。
- **US-D02 离开页面后继续运行**：作为远程使用者，我希望关闭标签页、手机锁屏或切换网络后进程仍继续运行，以便长任务不依赖浏览器在线。
  验收要点：
  - 浏览器取消连接只解除附着；
  - 服务存活期间会话继续运行，可从列表或原链接再次进入。服务端内部消息非法或无法编码时，以 1011 关闭当前连接，不记录载荷、不终止持久会话。
- **US-D03 自动重连与缺失输出续接**：作为使用者，我希望断线或回到前台后自动恢复终端，以便继续工作且不漏掉断线期间保留的输出。
  验收要点：
  - 断线后退避重连，重连期间显示不遮挡终端的“正在恢复…”提示；
  - 代际和续接点有效时只追加缺失字节，即使更早历史被覆盖也保留现有终端与查找状态；
  - 否则重置终端（回放期间保留旧画面与图片，完成后同帧切换），未截断时回放缓冲，已截断时仅初始化模式、不回放旧文本，并请求程序重绘，再无缝接入实时流；
  - 完整重置清除旧查找标记并提示按 Enter 重查；
  - 慢客户端断开而不阻塞 PTY；
  - 普通 pageshow 不替换连接；
  - 回到前台或发送终端输入时仍为 OPEN 的连接先以无副作用的提交查询探测，3 秒内有回复即保留连接与阅读位置，隐藏期间漏收输出、探测超时或连接已断时才续接，bfcache 恢复同样续接；
  - 释放后的迟到事件不再更新页面；
  - 连接正常时顶栏只显示有名称和提示的状态点。
- **US-D04 查看保留历史**：作为使用者，我希望重开会话后查看最近输出，并知道更早的记录是否已被覆盖，以便判断历史是否完整。
  验收要点：
  - 默认每会话保留 2 MiB 原始字节，可配置；
  - 截断后的完整恢复不把任意后缀当作完整屏幕，而是清空不可恢复的历史并请求程序重绘，不显示历史丢弃或重绘请求提示；
  - 查找范围与复制缓冲中的截断标记仍保留；
  - 通过短暂改变实际 PTY 列数再恢复请求重绘，不注入按键、不接管控制，并发控制端 resize 优先；
  - 程序不响应时不保证恢复成功，已退出程序不能重绘；
  - 诊断/复制原始缓冲仍可用，有界缓冲不是永久日志或完整 VT 状态。
- **US-D05 多设备观察**：作为在电脑与手机间切换的使用者，我希望同时打开同一会话并观察输出，以便跨设备接续任务。
  验收要点：
  - 各端连接同一个 PTY；
  - 后连接设备默认观察，按控制端网格显示并允许平移；
  - 观察端窗口或键盘变化不改变共享 PTY 尺寸；
  - 终端顶部的状态提示悬浮在终端上方，显示或关闭都不改变终端尺寸、不发送 resize，全屏程序不因此重绘。
- **US-D06 接管输入与尺寸控制**：作为观察端使用者，我希望主动接管终端，以便在当前设备上输入并采用适合它的终端尺寸。
  验收要点：
  - 显示控制设备；
  - 输入、发送草稿、点键盘按钮或显式接管可转移控制权；
  - 仅控制端可改变尺寸（脚本经 REST 调整尺寸的规则见 US-S19）；
  - 控制端断开后等待下一次接管，终端设备查询避免重复应答。
- **US-D07 阅读与恢复画面**：作为使用者，我希望滚动历史后能回到最新输出，并能清屏或重新同步，以便处理长输出和异常画面。
  验收要点：
  - 提供滚动到最新位置（窄于 640px 时由终端内“回到最新”浮动按钮承担）、清屏和重新同步；
  - 重新同步与重开页面使用同一安全快照恢复路径，历史截断时清空不可恢复内容并请求重绘；
  - 窄屏终端离开底部（含观察端平移离开最新行）时右下角显示带文字的“回到最新”，点击回到最新输出且不取得焦点、不开合键盘，回到底部自动隐藏；
  - 这些操作不创建新会话，也不结束进程；
  - 复制全部缓冲独立于当前可见区域。
- **US-D08 全屏与字体**：作为使用者，我希望进入全屏并调整字体，以便在不同屏幕上留出更多终端空间。
  验收要点：
  - 浏览器支持时可进入和退出原生全屏（窄于 640px 时在终端菜单中）；
  - 不支持时浏览器标签页提示添加到主屏幕，主屏幕 Web App 中不显示全屏入口；
  - 字体可在 8–20px 间调整，只保存在当前浏览器、不跨设备同步（各设备屏幕大小不同），并用于终端布局；终端与代码区内置 `Maple Mono NF CN`（含拉丁、制表符、Nerd Font 图标及按需加载的 `unicode-range` 中文切片），保证中英文 2:1 等宽对齐。
- **US-D09 查看退出结果**：作为使用者，我希望程序结束后仍能看到退出码和最后输出，以便确认成功或排查失败。
  验收要点：
  - 最终输出排空后发布退出；
  - 退出码与原始缓冲保留至手动移除；
  - 已退出会话不再接受终端输入；
  - 退出后的前台恢复与手动重新同步仍使用安全 WebSocket 快照，缓冲已截断时清空不能重建的历史，不显示历史丢弃或无法重绘提示，不把原始后缀写入终端。混合会话的 TUI 自行退出时同样保留最后输出，并标记为已中断、提供恢复到聊天或终端（US-Q10）。
- **US-D10 关闭和移除会话**：作为使用者，我希望明确终止不再需要的任务，再清除会话记录，以便管理进程与列表。
  验收要点：
  - 关闭前确认，先 SIGHUP、超时后 SIGKILL，并按平台能力清理后代；
  - 关闭后保留输出；
  - 移除前另行确认且只允许移除已退出会话；
  - 不删除工作树；
  - macOS 自守护进程边界见 [部署说明](../deployment/services.md#平台差异)。混合会话的结束操作称为“停止会话并归档”（非破坏性确认）：先中断进行中的回合，记录改为已关闭并进入所属工作树的“已归档”，单窗格会话页随后返回首页，“已归档”保持折叠，不自动展开，分屏时只移除该窗格；删除记录另行确认（US-Q12）。
- **US-D11 查找终端输出**：作为阅读长输出的使用者，我希望在当前终端缓冲中查找文字并复制匹配，以便定位错误而不向程序发送输入。
  验收要点：
  - 终端菜单“查找”、Ctrl+Shift+F 或 macOS Cmd+F 打开查找栏，普通 Ctrl+F 不拦截；
  - 从当前视口开始，支持大小写、全词、正则、上/下一个匹配及 Enter/Shift+Enter，Esc 关闭；
  - 显示当前序号、无匹配与无效正则，达到 1000 个时明确只统计前 1000 个；
  - 范围限当前 xterm 缓冲（默认最多回看 10000 行），全屏程序只查当前屏幕，服务端历史截断另行提示，不检索已覆盖输出或服务端原始字节；
  - 输入法组合期间不查找、不误触 Enter/Esc；
  - 查找不写入 PTY、不接管控制、不改变共享尺寸或草稿；
  - 可复制选中，权限不足沿用手动复制；
  - 关闭、清屏及缓冲切换清除标记，完整回放期间暂停且完成后需重查，增量续接保留查找；
  - 桌面关闭后恢复终端/草稿焦点，触屏不强制弹出终端键盘，窄屏控件可换行。
- **US-D12 显示终端图片**：作为运行会输出图片的终端程序的使用者，我希望在浏览器终端里直接看到 Kitty 图形协议的图片，以便预览截图、图表和图像输出。
  验收要点：
  - 识别 APC `ESC_G…ESC\`；
  - 支持直接传输的 PNG、RGB、RGBA、分块传输、图片与放置 ID、图像编号、源矩形裁剪、按单元格缩放与偏移、`C=1` 光标策略及各类删除；
  - 查询由控制端浏览器在后续文本前答复，回放历史不回发旧响应；
  - 普通/备用屏幕的图片隔离；
  - `CSI 2J` 清屏删除对应放置，局部文本擦除不删除图片；
  - 图片随输出滚动并可随历史视口重新显示，历史截断释放对应放置；
  - omp 顶部裁剪及只重绘文字时保留正确图片，不依赖会被文本擦除删除的 xterm marker；
  - 解码、图像数量、放置及画布资源有界，超限请求被拒绝，后续尺寸变化超限时释放放置；
  - 图片只绘制在浏览器终端，不进入会话列表文本预览；
  - omp 18.12.6 使用 `PI_FORCE_IMAGE_PROTOCOL=kitty`（首次预置配置已设置），不承诺所有程序自动探测；
  - 不支持文件/共享内存介质、动画、Unicode 占位符和相对父放置，不支持的相对放置返回 `ENOTSUP`；
  - 负 z-index 图片仍显示在文字上方。

- **US-D15 查阅快捷键**：作为使用者，我希望从终端右上角查看全部 WebMux 快捷键，以便发现操作方式并确认生效范围。
  验收要点：
  - 右上角键盘按钮在 640px 及以上可见；窄于 640px（手机无实体键盘）时收入终端菜单“快捷键”，弹窗在 320px 内完整可见；
  - 弹窗分组展示键位，说明平台修饰键、Ctrl+B 前缀、焦点范围及快速切换会话（US-C18）。
  - 明暗主题与低高度横屏中可滚动查阅，标题和关闭按钮保持可见；
  - 按钮或 Esc 关闭后焦点返回入口；
  - 查阅不触发分屏、不向终端输入、不改变未发送草稿；
  - Shell 与 CLI 自有键位由目标程序决定。

分屏操作与布局恢复（US-D13–US-D14）见[分屏用户故事](terminal-splits.md)。

## E. 剪贴板与文件上传

- **US-E01 复制选中与全部缓冲**：作为使用者，我希望复制选中文字或当前服务端保留的全部输出，以便分享结果和排查问题。
  验收要点：
  - 桌面有选中时 Ctrl+C（macOS ⌘C）复制并清除选择，无选中时 Ctrl+C 发送中断；
  - Ctrl+Shift+C 不再复制；
  - 复制按钮旁显示对应快捷键且触摸设备隐藏；
  - 触摸选择提供复制按钮；
  - 菜单可复制全部缓冲；
  - 缓冲被截断时注明更早输出已覆盖。
- **US-E02 粘贴文本与降级操作**：作为使用者，我希望粘贴多行文本，并在剪贴板权限不可用时仍能手动操作，以便在 HTTP 或受限浏览器中输入。
  验收要点：
  - 提供 Ctrl+Shift+V 和粘贴入口；
  - 遵循目标程序的 bracketed paste 模式；
  - 剪贴板读写被拒绝时提供手动文本框；
  - 未启用 bracketed paste 的程序可能把换行当作提交。
- **US-E03 接收程序复制请求**：作为使用者，我希望终端程序的 OSC 52 复制请求能进入浏览器剪贴板，以便沿用 CLI 的复制操作。
  验收要点：
  - 当前可见终端的在线请求可复制，权限不足时手动复制；
  - 后台或被代码/聊天遮住的终端仅保留最新请求，显示待处理提示，主动点击后才复制或打开手动文本框；
  - 切换窗格不自动复制；
  - 历史回放不重复执行复制请求。
- **US-E04 多种方式上传文件**：作为使用者，我希望选择、拖放或粘贴文件和图片，以便向服务器上的 agent 提供素材。
  验收要点：
  - 文件选择支持多个文件依次上传；
  - 拖放与剪贴板文件进入同一上传流程；
  - 文件粘贴优先于伴随文本，普通文本仍按文本输入。
- **US-E05 插入上传路径**：作为使用者，我希望上传完成后自动获得可用的服务器路径，以便把文件交给终端程序。
  验收要点：
  - 成功后插入带 shell 引号的绝对路径且不回车；
  - 草稿模式下插入草稿；
  - 保存到本会话临时文件夹的 `uploads/` 而非工作区，同名文件以 ` (2)` 等后缀区分且不覆盖；
  - 会话删除（混合会话删除记录）后随文件夹清理。
- **US-E06 查看进度与取消**：作为使用者，我希望看到文件名、批次进度并随时取消，以便控制大文件上传。
  验收要点：
  - 显示当前文件、序号、百分比和等待终端恢复状态；
  - 单文件上限 100 MiB、上传期限 5 分钟；
  - 取消或失败清理未完成文件，不伪造成功路径。
- **US-E07 恢复期间的上传交接**：作为使用者，我希望重连、切换草稿或上传部分失败时仍能准确拿到已上传文件的路径，以便避免丢失素材或误输入。
  验收要点：
  - 路径等待输入目标就绪后插入；
  - 取消后不在重连时补插；
  - 切换为草稿时可交给草稿；
  - 已上传但未插入时提示真实路径，保留已成功插入的结果；
  - 退出会话拒绝新上传。

## G. 快捷指令与语音输入

- **US-G01 保存常用文字**：作为使用者，我希望保存常用命令或多行提示词，以便减少重复输入。
  验收要点：
  - 设置中可新增与编辑名称、正文和是否追加回车，名称必填且不重复，不含 `{`、`}` 与换行，初始化指令用 `{{名称}}` 引用它；
  - 正文统一换行并移除末尾换行；
  - 最多 50 条；
  - 首次未保存列表时提供系统预设“恢复会话” `/resume`、“新会话” `/new` 与“WebMux 工具” `{{webmux}}`（旧版本保存的“临时文件夹”原样保留），之后可在设置的“添加系统预设”菜单补回缺少的预设；
  - 旧版本保存的未命名或重名指令在服务端读取时按正文自动命名（如 `/resume`、`/resume 2`），下一次保存列表时一并写回。
- **US-G02 一键发送或插入**：作为使用者，我希望从终端或底部工具栏打开快捷指令，以便把常用内容送往当前输入目标。
  验收要点：
  - 菜单显示名称、正文摘要与回车标记；
  - 直接模式按配置发送正文或正文加回车；
  - 草稿模式只插入正文，不因回车选项提交草稿；
  - 发送时清除软键修饰状态；
  - 混合会话聊天视图的入口在输入框底部、发送按钮左侧（顶栏不再显示），只插入消息输入框，不自动发送；
  - 快速开始页 `/new` 的输入框底部、发送按钮左侧同样有该入口：只在光标处（或替换选区）插入正文，不自动发送，`enter` 选项不起作用，草稿照常保存；发送或创建中禁用；“管理快捷指令”进入设置页的快捷指令分区，返回后草稿仍在。
- **US-G03 排序与删除**：作为使用者，我希望调整指令顺序并删除不再使用的内容，以便把常用项放在前面。
  验收要点：
  - 设置页每行末尾只有一个“⋯”操作按钮，菜单提供编辑、上移、下移（首行不能上移、末行不能下移）和需确认的删除；点整行也可编辑；
  - 顺序保存；
  - 主动清空列表后保持空列表，不重新生成默认项。
- **US-G04 服务端保存与跨设备更新**：作为使用者，我希望指令跨设备持续可用，并能实时看到其他设备的修改，以便保持自己的指令列表一致。
  验收要点：
  - 列表通过 settings.json 保存并由 WebSocket 同步；
  - null 使用预置项，空数组保持清空；
  - 存储损坏保留原文件并禁写；
  - 冲突按 ID 重试一次，编辑失败保留正文；
  - 旧浏览器偏好不上传。
- **US-G05 不可发送时保留意图**：作为使用者，我希望终端未就绪时明确禁止直接发送，以便避免指令静默丢失。
  验收要点：
  - 断线、回放或退出时提示不可发送；
  - 草稿仍可接收指令；
  - 带回车提交的未知、失败、部分写入等结果有提示，重连后查询结果。
- **US-G06 告诉 agent 用临时文件夹与 WebMux 工具**：作为让 agent 交付截图、报告等文件的使用者，我希望一键插入 WebMux 工具说明，以便 agent 把交付物放到我能在代码栏查看的位置，并知道怎样用 shell 控制 WebMux。
  验收要点：
  - 系统预设是一条普通的快捷指令“WebMux 工具”（正文 `{{webmux}}`，不回车），与其他指令同样计入 50 条、可排序、编辑与删除；预设列表依次为“恢复会话”“新会话”“WebMux 工具”；
  - 运行正文含 `{{dir}}` 的指令时，先确保文件夹存在，把 `{{dir}}` 换成真实路径；含 `{{webmux}}` 时再换成服务端生成的说明（US-S06）；直接模式作为一次粘贴发送、草稿模式插入光标处，聊天视图插入输入框，均不回车；
  - 快速开始页（US-Q18）还没有会话，选择后正文连同 `{{dir}}`、`{{webmux}}` 原样插入输入框，发送时由服务端在会话创建后替换（规则同初始化指令：先 `{{dir}}`、说明最后插入且不再被替换；其他名称原样保留），输入框下方提示该占位符会在会话创建后替换；
  - 文件夹或说明不可用时提示原因（“临时文件夹不可用”或“WebMux 工具说明不可用”）且不插入；
  - 删除后可在“添加系统预设”中补回；正文可自行编辑并跨设备同步；旧版本保存的“临时文件夹”预设原样保留，不迁移；临时文件夹的完整说明移入手册的 `artifacts` 主题。

语音录音与识别设置（US-G07）见[语音输入用户故事](terminal-voice.md)。

## H. 手机、平板与触摸操作

- **US-H01 使用软键栏与软键盘摇杆**：作为手机或平板使用者，我希望直接点击终端特殊按键，或切换为软键栏内的摇杆，以便不依赖实体键盘高效操控 CLI 与 Agent，并避免控制键遮挡终端。
  验收要点：
  - 触摸设备默认显示可横向滚动的软键栏；软键栏的按钮没有外边框：键盘、粘贴、草稿、语音与快捷指令只显示图标（保留可访问名称与提示），其余按键显示文字；
  - 包含键盘、粘贴、快捷指令、`/`、`@`、`#`、`!`、Esc、Tab、回车（`↵`）、Ctrl、Alt、Shift、方向、Home/End、翻页和常用 Ctrl 组合键；
  - Ctrl/Alt 为一次性修饰；
  - Shift 点按为一次性、长按约 0.5 秒锁定并在再次点按后解除，锁定时按钮显示锁图标；
  - 可与 Tab、方向键、Home/End、翻页组成带 Shift 的序列，点按或锁定后对虚拟与实体键盘的后续输入同样应用 Shift；
  - 符号映射按 US 布局；
  - 软键栏左侧的键盘与粘贴按钮旁提供“展开摇杆／收起摇杆”开关；折叠时显示普通软键，无法操控时开关禁用，摇杆随软键栏显示或隐藏；
  - 展开偏好保存在本机浏览器；展开且当前客户端已接管控制、连接正常、进程未退出时，在软键栏内的独立一行显示摇杆（左侧 Esc、Tab、Ctrl+C 与回车 `Enter`，右侧左上角空格与十字方向键），观察模式或未接管时不显示；
  - 摇杆的方向键支持按住连发与不抬手滑动切向；摇杆激活时底部软键栏自动隐藏重复的 Esc、Tab、`↵`、方向键与 Ctrl+C（保留 Ctrl/Alt/Shift）；摇杆按键组直接沿用软键栏表面，不增加外层边框、背景或阴影；摇杆占用软键栏布局空间并自然压缩终端区域，不覆盖或拦截终端，终端仍可单指滑动滚动与长按选词。
- **US-H02 主动开合键盘**：作为触摸设备使用者，我希望自己决定何时打开虚拟键盘，以便阅读和点选时保留屏幕空间。
  验收要点：
  - 只有点击键盘按钮才主动唤起或收起；
  - 已唤起时点击方向键、Esc、Tab 等发送软键保持焦点、不收起键盘；
  - 打开快捷指令菜单或粘贴对话框时焦点转入弹层；
  - 进入终端、轻点或笔点终端、开启草稿、关闭弹窗和上传完成均不自动唤起；
  - 系统返回键收起键盘后，轻点、滑动或笔点终端不重新唤起，键盘按钮仍可重新打开；
  - 带笔或实体键盘的触摸平板也遵循此规则。
- **US-H03 滚动历史与 TUI**：作为触摸设备使用者，我希望用单指滑动查看终端内容，以便在没有鼠标滚轮时浏览长输出。
  验收要点：
  - 普通终端滑动滚动历史；
  - 启用鼠标交互的全屏 TUI 中转换为相应滚轮事件；
  - 不将滚动误作键入。
- **US-H04 双指手势不缩放**：作为触摸设备使用者，我希望双指捏合不会改变终端大小，以便在滑动或拿稳设备时不会因误触打乱输出和布局。
  验收要点：
  - 双指捏合或张开不改变字号、PTY 行列或滚动位置；
  - 终端区域阻止浏览器原生双指页面缩放，避免同类误触；
  - 字号仍通过终端菜单在 8–20px 间调整，只保存在当前浏览器、不跨设备同步；
  - 手势结束后恢复正常单指滚动与长按选择。
- **US-H05 长按选择复制**：作为手机使用者，我希望长按选词并拖动扩选，以便复制命令结果或错误信息。
  验收要点：
  - 约 0.5 秒长按选词；
  - 支持宽字符与跨行扩选；
  - 显示复制选中入口，权限不足时提供可手动复制的选中文字；
  - 选择不向终端输入。
- **US-H06 键盘视口与独立运行**：作为手机使用者，我希望键盘开合和横竖屏变化时仍能使用终端，以便在小屏幕持续工作。
  验收要点：
  - 页面按可见视口适配；
  - 终端菜单可锁定尺寸，锁定后键盘、浏览器地址栏、窗口或旋转引起的宽高变化都不改变 PTY 行列，终端按锁定时的网格显示，网格超出可用区域时由终端区域显示滚动条（不再叠加 xterm 自带滚动条）并默认贴住底部使最新输出与输入行可见，可滚动查看被挡住的部分；
  - 锁定时调整字号只缩放显示、不改变行列，关闭锁定后按当前可见视口重新适配；
  - 触屏设备用软键栏键盘按钮唤起键盘（直接或草稿模式）时，默认暂时保持 PTY 行列，并按锁定尺寸的方式贴底显示；
  - 键盘经按钮或系统方式（返回键、输入法收起键、iOS“完成”、失焦）收起且视口高度稳定后才结束保持，开合一次不发送尺寸变化；焦点转到粘贴弹窗、查找栏等其他输入框时不结束，等键盘真正收起；约 1.5 秒未检测到键盘也结束；
  - 保持期间宽度与字号变化照常适配；终端菜单“键盘弹出时保持尺寸”可关闭，选择保存在本机浏览器并对所有会话生效；
  - 终端输入关闭自动大写、纠错和拼写检查；iOS 键盘扩展（如 Typeless 语音输入）一次提交的整段文字完整写入终端一次，不再只剩首字；输入法组合在失焦或切到后台时重置，未发出的 `keyup`、直接候选提交（`insertFromComposition`）与输入法换行（`insertLineBreak`/`insertParagraph`）不阻塞后续输入或回车；
  - 浏览器标签页中的窄屏单窗格聊天阅读态解除根文档滚动锁定与 `scrollTo(0, 0)` 强制归位，以交由浏览器原生收起工具栏；聚焦输入、打开代码栏、分屏、桌面宽度、主屏幕独立模式与终端视图保持固定视口壳层，模式切换时重置视口高度基线（US-Q05）；
  - 支持浏览器添加到主屏幕或安装为应用后的独立显示；
  - 依赖平台的键盘、选择菜单与锁屏行为仍需真机验证。
- **US-H07 桌面启用底部工具栏**：作为使用鼠标或实体键盘的使用者，我希望也能显示软键工具栏，以便点击常用操作。
  验收要点：
  - 终端菜单可强制显示或关闭底部工具栏；
  - 手机的代码视图不提供快捷指令入口；回到终端视图后由软键栏进入。
- **US-H08 窄屏紧凑顶栏**：作为在手机或主屏幕 Web App 中查看 agent 的使用者，我希望顶栏只保留身份和视图切换，其余操作按用途归类，以便看清会话名称、把高度留给终端，并一眼知道自己在哪个视图。
  验收要点：
  - 窄于 640px 时顶栏单行且不横向滚动，只常驻返回、状态点加标题、“会话视图”切换（普通会话“终端 | 代码”，混合会话“聊天 | 终端 | 代码”，带文字，不再另设代码按钮）和终端菜单；分屏在手机上不常用，收入终端菜单“窗格”组（新建/加入会话、分屏、放大、关闭窗格）；
  - 普通会话与混合会话的“会话视图”是同一个标签页控件（`tablist`），文案固定，选中项表示当前视图（`aria-selected`）；页面加载、会话信息到达和切换进行中不改换控件，混合会话确认后在前面加上“聊天”，切换目标未知时各项原位保留且不选中；
  - 状态点在标题之前；连接异常时点脉动（尊重减少动效设置），“重连中”等文字显示在标题下方小字，不挤掉标题；
  - 草稿开关在触屏软键栏快捷指令旁，软键栏隐藏（代码视图或非触屏窄屏）时在终端菜单首组；
  - 终端菜单按“会话 / 剪贴板 / 终端 / 显示”分组，窄屏另含全屏、上传文件、快捷键，名称与禁用条件不变；滚动到最新位置由终端内“回到最新”浮动按钮承担；
  - 返回与菜单为触控尺寸，其余顶栏控件为紧凑触控尺寸；
  - 320px 下无横向溢出，393px 下完整显示较短标题；
  - 宽屏保留既有按钮（含草稿、快捷键）并增加分屏菜单；
  - 宽屏状态点紧随标题，右侧按“聊天 | 终端”、图标操作（上传、滚动到最新）、快捷指令、草稿、代码、全屏、分屏、菜单排列；
  - 返回按钮始终可用。
- **US-H09 安装为应用**：作为在手机或桌面常用 WebMux 的使用者，我希望知道当前地址能否安装并一键安装，以便像本地应用一样打开且不被地址栏占用空间。
  验收要点：
  - 设置页“安装应用”分区显示正以应用方式运行、本页刚完成安装，或在浏览器提供安装提示时显示未安装；
  - 没有提示时不断言未安装（已安装应用的普通标签页同样收不到提示），只说明未以应用方式打开；
  - Chromium 在安全上下文提供安装提示时显示“安装 WebMux”按钮并调用浏览器提示，提示只用一次；取消或提示 Promise 被拒绝时说明可从浏览器菜单安装，失败不产生未处理 rejection，安装后隐藏按钮；
  - 没有提示时说明 Chrome、Edge 与 macOS Safari 的菜单入口；
  - iOS / iPadOS 显示“分享 → 添加到主屏幕”与重新输入 Token 的步骤，HTTP 地址可添加但推送仍需 HTTPS；
  - 非安全上下文（既非 HTTPS 也非本机回环地址）明确提示“当前地址不能提供完整 PWA 能力”并指向 HTTPS 入口；
  - manifest 声明 `id`、`lang`，以 `application/manifest+json` 提供，192/512 图标尺寸与声明一致；
  - 不提供离线启动，Service Worker 仍只在开启推送时注册。

US-H09 图标验收：应用图标与页头标志一致。maskable 版本为系统裁切保留安全边距，Apple 主屏幕图标交由系统裁圆角。
