# 将聊天交给另一个 Agent

在聊天页顶栏打开「会话菜单」，选择「更换 Agent…」继续当前对话，或选择「交接到新聊天…」另开一段对话。
历史由服务端读取；浏览器无需保留旧时间线。先生成预览、检查历史，再发送独立的新任务。

## 选择交接方式

| 入口          | 对话与工作位置                         | 适用场景           |
| ------------- | -------------------------------------- | ------------------ |
| 更换 Agent…   | 保留同一对话与原工作位置；位置只读     | A → B → A 接力     |
| 交接到新聊天… | 新对话；默认来源位置，可改目录或工作树 | 分支探索、独立任务 |

1. 选择目标 Agent，可填写目标支持的模型 ID；留空沿用保存的模型。
2. 新聊天可在「位置」选择直接目录、已有工作树或新建工作树。新工作树预览时不创建，首次发送才分配目录与新分支。
3. 在「交接后的用户任务」填写新任务，点击「生成预览」。历史与用户任务独立保存和发送。
4. 检查预算、覆盖范围与省略数量。需要时编辑「历史正文」，再点击「发送交接」。成功后可「打开目标聊天」。

## 检查历史与保存编辑

预览显示完整或增量历史、目标线程、冻结位置、预算来源、上下文占用和恢复工具能力。
A → B → A 在身份可恢复时复用 A 的线程，只补充未见内容；必要时返回需单独审阅的新草稿。
历史中的来源工作目录仅作参考，目标实际位置以位置选择为准。

「查看省略历史」按固定来源位置分片读取旧项，不会自动把读取的文字追加到新任务。
未修改的历史可按受支持版本使用原生注入；手工编辑正文后标为手工上下文，使用 inline。
历史和新任务在预览生成后自动保存到服务端，关闭弹窗、切换页面、刷新及服务重启后可恢复。
手机与桌面沿用相同的菜单入口、预览和保存流程。

## 过期、冲突与投递恢复

- 新回合或配置变化把原预览标为过期，保留编辑；点击「重新预览」明确采用新的来源位置。
- 另一设备修改相同 revision 时，保留本地文字；可「读取服务端版本」或「保留编辑重新预览」。
- 超预算的历史和任务保留完整原文，可继续缩减；不会自动截短或丢掉其中一份。
- 准备中的投递只允许继续原命令；明确失败后可「明确重试交接」，沿用已创建资源。
- 「结果待对账」表示可能已经发送，不提供盲目重试；打开目标聊天检查并刷新对账状态。
- 成功交接的历史保持只读，新任务输入清空以便准备下一次交接；原任务仍保存在已投递记录中。

## 本设备草稿与隐私

生成预览前的任务、选项、附件引用，以及尚未确认保存的手工编辑存于本设备 localStorage。
未编辑的服务端历史不复制到该缓存；成功保存后清除对应未保存编辑。
目标记录被删除或来源暂时不可读取时，本设备未发送内容仍保留；来源恢复后可重新生成预览。
删除来源后，浏览器下次读取到不存在时清除该来源缓存；离线设备的缓存不会远程擦除，可清理站点数据。
服务端保存位置、备份和删除边界见[持久化清单](../persistence.md)，协议状态见[交接预览](../protocol/http-handoff.md)。
