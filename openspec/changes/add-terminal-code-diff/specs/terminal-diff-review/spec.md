# Spec Delta

## Purpose

让用户在当前终端会话内查看其启动目录所在 Git 工作树的未提交修改，在桌面同时观察 agent 输出和代码差异，在手机通过标签页完成同样的审阅。提供明确的修改来源、刷新时间和失败状态，保持原有终端交互与生命周期。

## ADDED Requirements

### Requirement: Diff 范围绑定会话启动工作树

系统 SHALL 从当前会话的真实启动目录定位 Git 工作树，不要求注册仓库，并展示工作树根路径。子目录启动 SHALL 查看所属工作树完整修改；终端内 `cd` SHALL NOT 改变该绑定。已知工作树身份失效 SHALL 显示不可用，不自动切换到其他仓库。

#### Scenario: linked worktree 子目录和直接会话

- **WHEN** 用户进入从 linked worktree 子目录启动的会话，该仓库未加入注册清单
- **THEN** Diff 显示该 linked worktree 的根路径和修改，不展示主工作区或其他 linked worktree 的修改，不自动注册仓库

#### Scenario: 启动工作树被删除或替换

- **WHEN** 工作树目录消失，或同路径目录的 Git/文件系统身份与已绑定目标不同
- **THEN** Diff 显示目标不可用，清除可发送的代码选择，原终端仍按自身连接状态运行

### Requirement: 修改来源明确且只读

系统 SHALL 分组展示未暂存、已暂存、未跟踪文件。同文件在索引与工作区均有修改时 SHALL 分别列出。未暂存比较索引与工作区，已暂存比较 HEAD 与索引，未跟踪文本按新增展示；无 HEAD 的仓库以空树比较索引。系统 SHALL NOT 隐式暂存、提交、回退、fetch 或展示忽略文件内容。

#### Scenario: 同文件同时暂存和继续修改

- **WHEN** 用户修改并暂存文件后再次修改它
- **THEN** 两组各出现一个条目，选择后分别看到对应比较双方，不合并成含义不清的整体差异

#### Scenario: 首次提交前的仓库

- **WHEN** 仓库没有 HEAD，索引有文件，另有未跟踪文件
- **THEN** 已暂存文件作为相对空树的新增展示，未跟踪文件独立展示，读取不创建提交

### Requirement: 统一 diff 提供双方准确行号

系统 SHALL 展示文件路径、修改类型、统一 diff 块、增删行及旧/新双方行号；上下文行拥有双方行号，新增行只有新行号，删除行只有旧行号。重命名 SHALL 展示旧/新路径。无文本差异的模式变更、重命名、二进制和子模块 SHALL 提供对应提示，不伪造文本行。

#### Scenario: 新增、删除和无末尾换行

- **WHEN** 文件包含新增行、删除行或无末尾换行标记
- **THEN** 各行与标记按 Git 差异语义展示，标记不计入代码行号；整文件删除仍可查看旧侧行号

#### Scenario: 二进制或只有重命名

- **WHEN** 所选条目为二进制文件或没有文本修改的重命名
- **THEN** 展示修改类型和路径信息，提供文件级引用，禁用不存在的行级选择

### Requirement: 桌面右侧面板与窄屏标签布局

视口宽度至少 1024 CSS px 时，终端页 SHALL 在左侧保留终端，右侧展示可折叠 Diff 面板；更窄时 SHALL 提供“终端 / Diff”标签，默认终端。布局 SHALL 保持单个原有终端实例与连接，隐藏终端不向 PTY 发送零尺寸；重新显示时按实际可见尺寸调整。Diff 内长代码 SHALL 独立滚动，不撑宽页面。

#### Scenario: 桌面同时查看与折叠

- **WHEN** 用户在 1440px 视口中打开终端页，随后折叠并重新打开 Diff 面板
- **THEN** 展开时左终端与右 Diff 同时可见，折叠时终端获得空间，同一 agent 继续运行且终端尺寸随可见区域更新

#### Scenario: 移动端切换和旋转

- **WHEN** 用户在 390px 视口切到 Diff、接收 agent 新输出，再返回终端或旋转设备
- **THEN** 标签按新视口布局显示，原会话输出继续接收，返回终端没有因切标签新建 PTY、清空已有内容或发送零尺寸；Diff 标签不显示终端软键栏或主动唤起键盘

### Requirement: 刷新具有明确的新旧状态

系统 SHALL 在 Diff 首次可见、重新显示、可见页面回前台、终端重连和手动刷新时读取最新修改，显示读取时间。后台或隐藏 Diff SHALL NOT 持续轮询 Git。刷新失败 SHALL 保留可辨识的旧结果并标记读取失败；旧请求 SHALL NOT 覆盖新文件、新会话或较新请求的结果。刷新改变所选内容 SHALL 清除行选择。

#### Scenario: agent 改写文件后刷新

- **WHEN** 用户已选择文件行，agent 随后改写该文件，用户点击刷新
- **THEN** 展示新差异和读取时间，原行选择失效；若文件不再有差异则提示并取消文件选择

#### Scenario: 快速切文件时返回乱序

- **WHEN** 用户先选 A 后选 B，A 的读取晚于 B 返回
- **THEN** 页面保持 B 的内容与选择，不被 A 的结果或错误覆盖

### Requirement: 有界读取与局部降级

系统 SHALL 限制 Git 读取时间、输出大小与展示行数，超限、冲突、无 Git、非 Git 目录和权限故障 SHALL 提供明确局部状态，不显示为干净。过大或不可读条目 SHALL 保留可用文件摘要，不提供被截断/无法定位的行选择。符号链接 SHALL 展示链接自身变化，不读取工作树外目标内容。

#### Scenario: 普通目录或注册存储故障

- **WHEN** 会话启动目录不是 Git 仓库，或 Git 可用但注册清单存储不可用
- **THEN** 前者显示不支持 Diff，后者仍能按会话目录读取 Diff；两者都保留原终端输入、重连和上传

#### Scenario: 超大、冲突或外部符号链接

- **WHEN** 所选文件超过限制、存在未合并冲突，或是指向工作树外文件的符号链接
- **THEN** 大文件显示受限原因，冲突文件显示未合并提示，链接仅展示链接自身；任何情况不阻塞 PTY 输出或泄露链接目标内容

### Requirement: Diff 接口沿用访问边界

只读修改与 diff 接口 SHALL 受现有 API 认证与 Origin 策略保护，以会话 ID 和服务器返回的文件标识定位目标。客户端任意绝对路径、越界路径或伪造文件标识 SHALL 被拒绝；内容 SHALL 作为文本渲染，不执行 HTML、终端控制序列或代码。Diff 功能 SHALL NOT 改变终端帧协议及工作树删除保护。

#### Scenario: 未认证或越界读取

- **WHEN** 客户端未认证，或尝试指定另一个工作树路径、`../` 路径或不属于当前变化列表的文件标识
- **THEN** 服务拒绝读取，未认证请求遵循现有认证错误合同，越界请求不返回目标内容

#### Scenario: 代码含 HTML 与控制字符

- **WHEN** 文件包含脚本标签、HTML 或 ANSI 控制字符
- **THEN** Diff 显示为可辨识的代码文本或转义字符，不执行脚本、不改变终端状态
